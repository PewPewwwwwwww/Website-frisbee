# Frisbee Organization Website

A web-based platform for a Frisbee organization that makes team registration, player management, events, champions, MVPs, and community information easier to manage.

## Features

- Team Registration
- Player Management
- Team Profiles
- Event Information
- Champions and MVPs
- Event Gallery
- Admin Dashboard

## Technologies

- React.js
- JavaScript
- Python
- MySQL

🚧 Currently in development.
